# Yunma — Site web

Site de présentation de la marque Yunma, cafés de spécialité sourcés à Yunnan, Chine.

**Slow Coffee. Slow Life. — 慢咖啡，慢生活**

## Structure

```
/
├── index.html     — Site single-page avec toutes les sections
├── style.css      — Styles (charte graphique yunma)
├── script.js      — Burger menu, FAQ accordéons, scroll
└── assets/
    └── logo.png   — Logo yunma
```

## Sections

1. **Accueil** — Hero avec tagline et piliers
2. **Cafés** — Sélections, FAQ, contact
3. **Histoire** — Story de la marque, FAQ
4. **Professionnels** — Offre B2B, FAQ, contact
5. **Contact** — Email, WhatsApp, Instagram
6. **Légal** — Mentions légales

## Déploiement GitHub Pages

1. Aller dans **Settings → Pages** du dépôt
2. Source : **Deploy from a branch**
3. Branch : choisir la branche souhaitée (ex: `main`), dossier `/` (root)
4. Sauvegarder — le site sera accessible à `https://[username].github.io/[repo-name]/`

## À personnaliser

- `hello@yunma.coffee` → votre adresse email
- `pro@yunma.coffee` → email professionnel
- `https://wa.me/33XXXXXXXXX` → votre lien WhatsApp (remplacer `33XXXXXXXXX` par votre numéro)
- `@yunma.coffee` → votre compte Instagram
- Section **Légal** → compléter les informations juridiques (forme juridique, SIRET, adresse)
- **Cafés** → remplacer les 3 cafés placeholder par vos vraies sélections
